# Dự Án Quản Lý Cửa Hàng Tiện Lợi (CUA_HANG_TIEN_LOI)

Hệ thống quản lý cửa hàng tiện lợi được phát triển bằng ngôn ngữ C# trên nền tảng Windows Forms, sử dụng mô hình 3 lớp (3-Tier Architecture) giúp quản lý nhân viên, ca làm việc, hàng hóa, nhà cung cấp, khách hàng và doanh thu một cách tối ưu.

## 🚀 Tính năng chính
- **Quản lý bán hàng:** Lập hóa đơn, thanh toán, tích điểm khách hàng.
- **Quản lý kho:** Nhập hàng, kiểm kê sản phẩm, quản lý danh mục và nhà cung cấp.
- **Quản lý nhân sự:** Phân công lịch làm việc, chấm công ca làm, quản lý KPI nhân viên.
- **Báo cáo & Thống kê:** Doanh thu ca làm việc, biểu đồ trực quan.

## 🛠️ Công nghệ sử dụng
- **Ngôn ngữ:** C# (Windows Forms)
- **Kiến trúc:** 3-Tier (GUI - BLL - DAL)
- **Cơ sở dữ liệu:** Microsoft SQL Server (Entity Framework)
